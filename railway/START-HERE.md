# راهنمای نصب روی Railway برای کسی که هیچی بلد نیست 🙂

این راهنما رو دقیقاً قدم‌به‌قدم دنبال کن. جایی که نوشته «اینو کپی کن» یعنی دقیقاً همون متن رو کپی کن، چیزی کم و زیاد نکن.

فقط **یک قسمت** هست که باید یه دستور رو اجرا کنی (قدم ۵) — بقیه‌ش کاملاً کلیک‌کردنه.

---

## قدم ۱: ساخت اکانت Railway

1. برو به آدرس: **https://railway.com**
2. روی دکمه‌ی **Login** یا **Start a New Project** بزن
3. با اکانت گیت‌هابت (یا گوگل) وارد شو — نیازی به ساخت پسورد جدید نیست

## قدم ۲: ساخت یک پروژه‌ی خالی

1. بعد از ورود، روی دکمه‌ی بزرگ **+ New Project** بزن
2. از لیست گزینه‌ها، **Empty Project** رو انتخاب کن
3. یک صفحه‌ی خالی (Canvas) براش باز میشه — همینجا می‌مونی

## قدم ۳: دانلود این پروژه

این پوشه (`railway/`) رو دانلود کن — اگه از گیت‌هاب می‌گیریش، بالای صفحه‌ی ریپو دکمه‌ی سبز **Code → Download ZIP** رو بزن، بعد فایل زیپ رو **Extract/استخراج** کن (راست‌کلیک روی فایل زیپ → Extract All).

## قدم ۴: کشیدن فایل روی Railway (مهم‌ترین قدم)

1. توی پوشه‌ای که استخراج کردی، برو داخل پوشه‌ی **`railway`**، دنبال فایلی به اسم **`railway-compose.yml`** بگرد
2. برو به تب مرورگرت که صفحه‌ی خالی Railway توش بازه
3. فایل `railway-compose.yml` رو با موس بگیر (کلیک نگه‌دار) و بکشش وسط صفحه‌ی Railway، بعد رهاش کن (Drag & Drop)
4. چند ثانیه صبر کن — Railway باید ۴ تا جعبه (سرویس) به اسم‌های `Postgres`، `panel`، `proxy`، `node` نشونت بده
5. یک دکمه‌ی **Deploy** (معمولاً گوشه‌ی پایین یا بالای صفحه) ظاهر میشه — روش بزن

حالا صبر کن، حدود ۲-۳ دقیقه طول می‌کشه تا همه‌چیز بالا بیاد. رنگ جعبه‌ها باید سبز بشه.

---

## قدم ۵: تنها کاری که باید توی «ترمینال» انجام بدی

نگران نباش، فقط باید یه برنامه نصب کنی و یه متن رو کپی/پیست کنی. پسورد دیتابیس، گواهی پنل، و API Key نود از قبل توی فایل `railway-compose.yml` ساخته شدن — نیازی به دست‌زدن بهشون نیست. تنها چیزی که باقی می‌مونه، گواهی خود سرویس **node**‌ه (چون آدرسش فقط بعد از ساخته‌شدنش مشخص میشه).

### ۵.۱ نصب Git Bash (اگه ویندوز داری)

1. برو به: **https://git-scm.com/downloads**
2. نسخه‌ی ویندوز رو دانلود و نصب کن (همیشه Next بزن، تنظیمات پیش‌فرض خوبه)
3. بعد از نصب، روی دسکتاپ یا استارت منو دنبال برنامه‌ای به اسم **Git Bash** بگرد و بازش کن — یه پنجره‌ی مشکی باز میشه، این همون «ترمینال»ه

> اگه مک داری، به‌جای این کار، برنامه‌ی **Terminal** رو باز کن (از Launchpad یا Spotlight با تایپ "Terminal" پیداش می‌کنی) — از قبل روش نصبه.

### ۵.۲ پیدا کردن یک آدرس از Railway

1. برگرد به صفحه‌ی Railway
2. روی جعبه‌ی **node** کلیک کن (تا بازش کنه)
3. روی تب **Variables** بزن (بالای صفحه‌ش)
4. توی لیست، دنبال چیزی به اسم `RAILWAY_PRIVATE_DOMAIN` بگرد
5. مقدارش (یه متنی شبیه `node.railway.internal` یا `abc123.railway.internal`) رو کپی کن (روش کلیک کن تا کپی بشه، یا کنارش آیکون کپی هست)

### ۵.۳ اجرای دستور

توی همون پنجره‌ی Git Bash (یا Terminal مک) که باز کردی، باید بری به همون پوشه‌ای که فایل‌ها رو استخراج کردی. مثلاً اگه توی Downloads هست:

```bash
cd Downloads/railway
```

(اگه اسم پوشه یا مسیرش فرق داره، مسیر درستش رو بذار — می‌تونی فایل‌ها رو توی File Explorer باز کنی و از بالای صفحه مسیر رو ببینی)

بعد این دستور رو بزن، ولی به‌جای آخرش، همون آدرسی که توی قدم ۵.۲ کپی کردی رو بچسبون:

```bash
bash scripts/railway-cert.sh node.railway.internal
```

Enter بزن. یه متن طولانی روی صفحه میاد که شامل چند تا بخشه:
- یه بخش با عنوان `مقدار *_CERT_B64`
- یه بخش با عنوان `مقدار *_KEY_B64`
- یه بخش با عنوان گواهی کامل (شروع میشه با `-----BEGIN CERTIFICATE-----`)

## قدم ۶: پیست‌کردن نتیجه توی Railway

1. برگرد به Railway → جعبه‌ی **node** → تب **Variables**
2. دنبال متغیری به اسم `SSL_CERT_B64` بگرد، روش کلیک کن، مقدارش رو پاک کن و به‌جاش، اون رشته‌ی طولانی که زیر عنوان `مقدار *_CERT_B64` توی ترمینال چاپ شد رو پیست کن
3. همین کارو برای `SSL_KEY_B64` با اون یکی رشته (`مقدار *_KEY_B64`) انجام بده
4. Railway ازت می‌پرسه دیپلوی مجدد بشه یا نه — بزن **Deploy** یا **Redeploy**

---

## قدم ۷: باز کردن پنل و ساخت اکانت

1. توی Railway، روی جعبه‌ی **proxy** کلیک کن
2. تب **Settings** رو باز کن، توی بخش **Networking** دنبال **Generate Domain** بگرد و بزنش (اگه از قبل یه آدرس نداره)
3. یه آدرس شبیه `xxxxx.up.railway.app` بهت میده — روش کلیک کن تا باز بشه (این آدرس نهایی پنلته، جایی که با رفیقات به اشتراک می‌ذاری)
4. صفحه‌ی لاگین پنل باز میشه؛ روی دکمه‌ی **«دسترسی مالک» / Owner Access** بزن

### گرفتن کد ورود اولیه

1. برگرد به Railway → جعبه‌ی **panel** → تب **Deployments**
2. روی آخرین دیپلوی کلیک کن تا جزئیاتش باز بشه
3. توی بخش **Deploy Logs**، دنبال خطی شبیه این بگرد:
   ```
   Temporary access key: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
   ```
4. این کد رو کپی کن — فقط **۵ دقیقه** اعتبار داره، پس زود برگرد به صفحه‌ی «دسترسی مالک» و پیستش کن
5. بعدش ازت یوزرنیم و پسورد نهایی می‌خواد — هرچی دوست داری بذار و یادت باشه

اگه دیر شد و کد منقضی شد، فقط توی همون سرویس panel روی سه‌نقطه (⋮) بزن → **Restart** و دوباره از قدم ۲ همینجا شروع کن (یه کد تازه ساخته میشه).

---

## قدم ۸: اضافه‌کردن نود به پنل

1. حالا که وارد پنل شدی، از منوی کنار صفحه روی **Nodes** بزن
2. **Add Node** رو بزن
3. این اطلاعات رو پر کن:
   - **Address**: همون مقداری که توی قدم ۵.۲ کپی کرده بودی (مثل `node.railway.internal`)
   - **Port**: `62050`
   - **API Key**: از Railway → جعبه‌ی node → Variables → مقدار `API_KEY` رو کپی کن
   - **Certificate**: برگرد به همون متنی که ترمینال قدم ۵.۳ چاپ کرد، بخش «گواهی کامل» رو پیدا کن (شروع میشه با `-----BEGIN CERTIFICATE-----`) و کاملش رو اینجا پیست کن
4. بزن **Create**

اگه چند ثانیه بعد رنگش سبز شد، یعنی همه‌چی درسته! 🎉

---

## قدم ۹ (اختیاری): ساخت اینباند برای اتصال کاربرها

توی پنل → **Core Settings**، محتوای فایل `inbounds/ws-tls.json` (توی همین پوشه) رو به آرایه‌ی `inbounds` اضافه کن. جزئیات کامل‌ترش رو می‌تونی از کسی که این پروژه رو بهت داده بپرسی، چون بستگی به دامنه‌ای داره که برای node هم می‌سازی.

---

## اگه یه‌جا گیر کرد

عکس بگیر از صفحه‌ای که توش گیر کردی (چه Railway، چه پنل، چه ترمینال) و همون عکس رو با توضیح کوتاه («اینجا گیر کردم») به کسی که این پروژه رو بهت داده نشون بده — با یه نگاه به عکس معمولاً میشه فهمید مشکل کجاست.
