# PasarGuard Deploy — پنل + نود

این ریپو دو تا روش کاملاً جدا برای بالا آوردن PasarGuard (پنل + نود) داره. فقط یکی از این دو تا رو لازم داری، بسته به اینکه کجا می‌خوای دیپلوی کنی:

## 📁 `railway/` — اگه روی **Railway.com** دیپلوی می‌کنی

اگه از سرویس Railway استفاده می‌کنی (همونی که تا الان باهاش کار کردیم)، فقط برو توی پوشه‌ی `railway/` و فایل **`START-HERE.md`** رو باز کن. اونجا از صفر تا صد، بدون فرض هیچ دانش فنی‌ای، توضیح داده شده.

## 📁 `vps-docker-compose/` — اگه روی یک سرور/VPS خودت دیپلوی می‌کنی

اگه سرور لینوکسی خودت رو داری (نه Railway) و می‌خوای با Docker روش نصب کنی، برو توی پوشه‌ی `vps-docker-compose/` و فایل `README.md` اونجا رو بخون.

---

⚠️ این دو پوشه **کاملاً مستقل** از همدیگه‌ن. فایل‌های پوشه‌ی `railway/` فقط برای Railway کار می‌کنن، فایل‌های `vps-docker-compose/` فقط برای یک سرور معمولی. قاطی‌شون نکن.

---

## آپلود روی گیت‌هاب

اگه می‌خوای این پروژه رو خودت روی گیت‌هاب بذاری تا بعداً از اونجا دانلودش کنی یا به بقیه بدی:

### روش ۱: از طریق سایت گیت‌هاب (بدون نیاز به ترمینال)

1. برو به **https://github.com** و وارد اکانتت شو (یا بساز اگه نداری)
2. گوشه‌ی بالا راست، روی **+** بزن → **New repository**
3. یه اسم بهش بده (مثلاً `pasarguard-deploy`)، روی **Public** یا **Private** بذارش (هرکدوم دوست داری)، و **Create repository** رو بزن
4. توی صفحه‌ای که باز میشه، دنبال لینک **uploading an existing file** بگرد و روش کلیک کن
5. تمام فایل‌ها و پوشه‌های این پروژه (`railway/`, `vps-docker-compose/`, `README.md`, `.gitignore`) رو بکش و اونجا رها کن (Drag & Drop)
6. پایین صفحه، دکمه‌ی سبز **Commit changes** رو بزن

همین. ریپو آماده‌ست و لینکش رو می‌تونی به هرکسی بدی.

### روش ۲: از طریق ترمینال (اگه با Git راحتی)

```bash
cd pasarguard-repo
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/<یوزرنیمت>/<اسم-ریپو>.git
git push -u origin main
```

(قبلش باید یه ریپوی خالی توی گیت‌هاب ساخته باشی — دقیقاً مراحل ۱ تا ۳ روش ۱ بالا)
